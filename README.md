# Device Log Summarizer CLI Tool

A command-line tool that reads device telemetry data from a CSV file, computes per-device statistics, filters out overheated devices, and generates a bar chart of average temperatures.

---

## Project Structure

```
device-log-summarizer/
├── device_telemetry.csv    # Input data: device_id, status, temperature
├── sanitizer.py            # Section 1: cleans a list of raw sensor readings
├── summarizer.py           # Section 2: reads CSV, aggregates stats, exports JSON
├── visualizer.py           # Section 3: reads JSON output, generates bar chart
├── main.py                 # CLI entry point — runs all three sections in order
├── output_summary.json     # Generated by summarizer.py
├── temperature_summary.png # Generated by visualizer.py
├── PROMPT_LOG.md           # AI collaboration log (required by Section 3)
└── README.md               # This file
```

---

## Requirements and Setup

**Python:** 3.8 or later (tested on 3.15.2)

**Dependency:** `matplotlib` is required for Section 3 (chart generation). The other sections use only the Python standard library.

Install matplotlib:
```bash
pip install matplotlib
```

No other packages are needed.

---

## Running the Full Pipeline

To run all three sections in order:

```bash
python main.py
```

This will:
1. Run Section 1 unit tests
2. Read `device_telemetry.csv`, compute statistics, write `output_summary.json`, and print a summary table
3. Read `output_summary.json` and write `temperature_summary.png`

---

## Running Each Section Separately

**Section 1 — sensor sanitization tests:**
```bash
python sanitizer.py
```

**Section 2 — CSV processing and JSON export:**
```bash
python summarizer.py
```

**Section 3 — bar chart generation:**
```bash
python visualizer.py
```

Section 3 requires `output_summary.json` to already exist (run Section 2 first).

## How Each Section Works

### Section 1 — `sanitizer.py`

Function: `clean_sensor_readings(readings)`

Takes a list of mixed inputs and returns a cleaned list of floats, applying these rules in order:

1. If input is `None` or not a list, return `[]`
2. Skip `None` items
3. Try to convert each item to `float`; skip anything that raises `ValueError` or `TypeError`
4. Skip `float('nan')` and `float('inf')` — these pass `float()` conversion but would silently corrupt any average computed from them
5. Skip values less than `0`
6. Clip values greater than `500.0` to `500.0`

The file also contains `run_tests()` which runs 4 test cases:
- Normal mixed input (strings, None, negative, clipping)
- Empty list, None input, all-invalid input
- Boundary values at `0.0`, `499.99`, `500.0`, `500.01`
- `float('nan')`, `float('inf')`, `float('-inf')`

### Section 2 — `summarizer.py`

Reads a CSV file with columns `device_id`, `status`, and `temperature`.

For each `device_id`, computes:
- `total_records`: number of rows for that device
- `average_temperature`: mean of temperature values, rounded to 2 decimal places
- `error_count`: number of rows where `status == "ERROR"`

Devices where `average_temperature > 80.0` are excluded from the output.

Saves results to a JSON file and prints a table to the terminal.

### Section 3 — `visualizer.py`

Reads `output_summary.json` and plots a bar chart of `average_temperature` per `device_id` using matplotlib.

Each bar has its temperature value displayed above it. The chart is saved as a `.png` file.

## Error Handling

The following error cases are handled in the code:

| Situation | Behavior |
| :--- | :--- |
| CSV file not found | Prints an error message to stderr and returns; does not crash |
| CSV missing required columns (`device_id`, `status`, `temperature`) | Raises a `ValueError` with a description of which columns are missing |
| A row has an empty `device_id` | Skips that row with a warning to stderr |
| A row has a non-numeric `temperature` value | Skips that row with a warning to stderr |
| A row has `temperature` of `nan` or `inf` | Skips that row with a warning to stderr |
| JSON file missing when running `visualizer.py` | Prints an error message and returns; does not crash |
| JSON file is empty (no devices) | Prints a warning and returns; does not crash |
